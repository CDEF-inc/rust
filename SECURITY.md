# Security Policy

This repository is CDEF-inc's fork of [rust-lang/rust](https://github.com/rust-lang/rust).

## Scope

Report here vulnerabilities in the changes made in this fork.
Vulnerabilities that are also present in the upstream project should be
reported to the upstream project as described in its security policy:
<https://www.rust-lang.org/policies/security>. If you are not sure which applies, report here and we will help
coordinate with upstream.

## Supported versions

The `rx-none-elf` branch maintained by CDEF-inc.

## Reporting a vulnerability

Please report security vulnerabilities privately, using GitHub's private
vulnerability reporting: open the **Security** tab of this repository and
click **Report a vulnerability**
(<https://github.com/CDEF-inc/rust/security/advisories/new>).

Please do not report vulnerabilities in public issues, pull requests or
discussions.

A useful report includes:

- the affected version, branch or commit;
- a description of the problem and its impact;
- the steps, input or code needed to reproduce it.

We will acknowledge the report, keep you informed while we investigate, and
agree with you on when the problem is disclosed. Fixes are published as a
GitHub security advisory together with the fixed version.
